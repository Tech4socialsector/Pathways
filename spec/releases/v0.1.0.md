# Pathways v0.1.0

**Release date:** 2026-10-23
**Commit:** [888f148](https://github.com/Tech4socialsector/Pathways/commit/888f148)
**Type:** Initial release baseline

## Summary

The first tracked version of Pathways, NLSIU's recruitment management app on the Frappe Framework. It covers recruitment from the pre-advertisement green sheet to the new joiner's first day, with a staff app at `/pathways` and a candidate portal at `/pathways/portal`. There is no earlier version to compare with.

## Feature highlights

- End-to-end recruitment workflow with configurable approval chains for each track.
- Candidate portal for applying, viewing applications, replying to interview invitations and accepting offers.
- Shortlisting and selection committees with scoring rubrics and a consolidated score sheet.
- Appointment orders with review, signature and PDF letters.
- Email rules and templates that can be changed without code.

## Modules

| Module | Included |
|---|---|
| Job and advertisement | Pre-recruitment green sheet and approval chain, job openings with per-track application forms, recruitment notifications and corrigenda, publishing tracker, Indeed XML and JSON job feeds, auto-close, job folders, colleague tagging |
| Applications | Candidate portal, candidate accounts (email or mobile login), Excel/CSV import |
| Shortlisting | Shortlisting committee and office order, eligibility check, scoring rubrics, shortlisting note, document ZIP and data export, regret emails |
| Interviews | HR interaction round with HR assessors, selection committee, Google Meet links and calendar, sharing files with the panel, panel scoring, consolidated scores |
| Selection | Reference checks (referee web form or recorded by staff), post-interview green sheet with approval chain, regrets after interview, panel thank-you and honorarium |
| Offer and joining | Appointment order templates, offer review and signature, PDF letter, candidate accept/decline on the portal or recorded by staff, onboarding document collection, joining confirmation, IT/Facilities requests |
| Reporting | Dashboard, analytics, communication log, Recruitment Pipeline, New Joiners and ERP Upload reports |
| Administration | Pathways roles, Roles & Permissions screen, Master Setup, Email Setup, Pathways Settings |

The release contains 68 DocTypes and three Script Reports.

## Deployment instructions

```bash
cd <bench>
bench get-app https://github.com/Tech4socialsector/Pathways.git --branch TFSS
cd apps/pathways && git checkout v0.1.0 && cd ../..
bench --site <site> install-app pathways
bench --site <site> migrate
bench --site <site> enable-scheduler
bench restart
```

`install-app` creates the roles, settings, email rules and templates, scoring rubrics, approval chains and other master data. The compiled frontend is included in this version.

## Upgrade considerations

- Requires Frappe v16 and Python 3.14 or later.
- Set up an outgoing Email Account before going live; Pathways sends many emails.
- Google Meet links and calendar sync need Google Workspace credentials.
- Complete the first-time setup in the [User Guide](../USER_GUIDE.md) (Part A).
