# Pathways v0.4.0

**Release date:** 2026-11-25
**Commit range:** [v0.3.0...v0.4.0](https://github.com/Tech4socialsector/Pathways/compare/v0.3.0...v0.4.0) (61f50b9..b2c3f9f)
**Type:** Minor release

## Summary

Pathways can be installed as an app on desktop and mobile, and the staff app works better on phones. Pull requests now follow a standard title format.

## Feature highlights

- Install Pathways from the browser, with its own icon and window.
- Welcome page with Sign in and Install app for signed-out visitors.
- Phone-friendly layout for the staff app.

## Module-wise changes

### Staff app
- **Introduced:**
  - Pathways is a Progressive Web App. The app name and colour follow Pathways Settings.
  - Signed-out visitors to `/pathways` see a welcome page with **Sign in** and **Install app**. Deep links still go to `/login`.
  - Signed-in staff are offered an install prompt. It opens the browser's install dialog, or shows step-by-step instructions for browsers without one (iOS, Safari, private windows).
  - **Install app** in the user menu.
- **Modified:**
  - On phones the sidebar is a drawer, search is a toggle in the top bar, the notification panel fits the screen, and the layout respects screen notches.
  - The collapsed sidebar shows centred icons, tooltips across the whole row and a clearer toggle.
  - Table toolbars no longer squeeze filters on small screens.
- **Problem addressed:** staff could not use Pathways comfortably on phones or open it like an installed app.
- **Roles affected:** all staff users.
- **Administrator action:** none.

### Development process
- **Introduced:** a GitHub Actions check that pull request titles follow Conventional Commits (`type(scope): description`), and a pull request template ([#1](https://github.com/Tech4socialsector/Pathways/pull/1)).
- **Roles affected:** developers.

## Technical changes

- New page renderer `pathways.pwa.PWAPage` (registered in `hooks.py`) serves `/pathways.webmanifest` and `/pathways-sw.js` from the site root, so the service worker can control `/pathways`.
- Service worker: pages are network-first with an offline fallback; hashed build assets and icons are cache-first. HTML pages, API responses, `/files` and `/private` are never cached, so no user data stays on the device after logout.
- App icons (standard, maskable, Apple touch, favicon) in `pathways/public/pwa`.
- `.github/workflows/pr-title.yml` and `.github/pull_request_template.md`.

## Breaking changes

None.

## Deployment instructions

```bash
cd <bench>
bench --site <site> backup
cd apps/pathways && git fetch && git checkout v0.4.0 && cd ../..
bench --site <site> migrate
bench build --app pathways
bench restart
```

No database patches in this release.

## Upgrade considerations

- Installing the app requires the site to be served over HTTPS.
- After deploying, users get the new version the next time they open or reload Pathways.
